# Stone Clicker

**Stone Clicker** - небольшая 2D-игра в жанре кликера, разработанная на Python с использованием библиотеки Pygame.

Цель игры - разрушать камни, получать за это монеты и покупать улучшения, которые позволяют наносить больше урона и быстрее зарабатывать игровую валюту.

## Возможности игры

- Разрушение камня нажатием левой кнопки мыши.
- Пять визуальных стадий повреждения камня.
- Получение монет после полного разрушения камня.
- Система улучшений:
  - увеличение урона;
  - увеличение награды за разрушение камня;
  - увеличение шанса критического удара;
  - увеличение силы критического удара.
- Критические удары с повышенным уроном.
- Две страницы меню улучшений.
- Визуальные эффекты: частицы, отображение нанесённого урона, тряска горы и анимация попадания.
- Графический интерфейс с собственными текстурами и иконками.

## Используемые технологии

- **Python 3.12**
- **Pygame 2.6.1**
