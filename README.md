## 📖 О проекте

**Stone Clicker** — это небольшая 2D-игра, в которой игроку предстоит разрушать камни с помощью кликов мыши, получать за это монеты и покупать различные улучшения.

Главная задача игры — постепенно увеличивать эффективность добычи монет с помощью улучшения урона, награды и критических ударов.

Проект разработан на языке **Python** с использованием библиотеки **Pygame**.

## 🎮 Игровой процесс

1. Нажимай на камень левой кнопкой мыши, чтобы наносить ему урон.
2. После полного разрушения камня получай монеты.
3. Используй заработанные монеты для покупки улучшений.
4. Увеличивай урон и характеристики критических ударов.
5. Продолжай разрушать камни и улучшать свои показатели.

## ⚙️ Система улучшений

В игре доступны четыре улучшения, расположенные на двух страницах меню.

| Улучшение | Описание |
|:---|:---|
| ⚔️ Урон | Увеличивает количество урона за один удар |
| 🪙 Награда | Увеличивает количество монет за разрушение камня |
| 🎯 Шанс крита | Увеличивает вероятность критического удара |
| 💥 Сила крита | Увеличивает урон критического удара |

Стоимость улучшений постепенно увеличивается после каждой покупки.

## 📦 Установка и запуск

### 1. Скачивание проекта

Склонируйте репозиторий:

```bash
git clone https://github.com/PavelDiler/Stone-Idle.git
```

Перейдите в папку проекта:

```bash
cd Stone-Idle
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

Активируйте его:

**Windows:**

```bash
venv\Scripts\activate
```

### 3. Установка Pygame

```bash
pip install pygame==2.6.1
```

### 4. Запуск игры

```bash
python main.py
```

## 🧩 Техническая реализация

Основная логика игры находится в файле `main.py`.

В проекте реализованы:

- Загрузка и отображение графических ресурсов.
- Обработка нажатий мыши.
- Расчёт обычного и критического урона.
- Проверка здоровья камня.
- Начисление игровой валюты.
- Покупка и расчёт стоимости улучшений.
- Обновление и отображение визуальных эффектов.
- Основной игровой цикл с ограничением частоты кадров.

Игровое окно имеет разрешение **640 × 480 пикселей**, а частота обновления ограничена **60 FPS**.

## ⚠️ Ограничения текущей версии

- Игровой прогресс не сохраняется после закрытия приложения.
- В игре отсутствует система звукового сопровождения.
- Игра работает в одном игровом режиме.
